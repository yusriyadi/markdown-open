# Markdown Open v1.1.0

- Paket instalasi macOS jauh lebih kecil: DMG sekitar 6 MB.
- Diagram Mermaid tampil otomatis di dokumen Markdown dan dapat digunakan offline.
- Dokumen kosong tetap terbuka; kegagalan membaca file ditampilkan tanpa menutup dokumen aktif.
- Ekspor PDF menunggu diagram selesai dirender dan mendukung shortcut ⌘P.

## Unduhan

Rilis ini tersedia untuk **macOS Apple Silicon (arm64)**:

- **DMG**: buka installer lalu seret Markdown Open ke Applications.
- **ZIP**: ekstrak lalu pindahkan Markdown Open.app ke Applications.
- **SHA256SUMS.txt**: checksum untuk memverifikasi file unduhan.

## Catatan

- Build belum ditandatangani dengan Apple Developer ID dan belum notarized. macOS dapat memblokir pembukaan pertama.
- Installer Windows belum tersedia; dukungan Windows masih eksperimental.
- Panduan build macOS dan persiapan Windows tersedia di [README versi ini](https://github.com/yusriyadi/markdown-open/blob/v1.1.0/README.md).
