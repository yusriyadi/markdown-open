# Markdown Open v1.1.1

- Header mengikuti scroll: sembunyi saat membaca ke bawah, muncul saat scroll ke atas atau kembali ke bagian paling atas. Berlaku di desktop, Android, dan web.
- Scroll di dalam diagram Mermaid tetap independen; header kembali saat membuka dokumen baru atau menggunakan navigasi keyboard Tab.
- Shortcut zoom halaman desktop dipulihkan: Cmd + +/=/− untuk zoom dan Cmd + 0 untuk reset pada macOS; Ctrl pada desktop lain.
- Android memakai package name baru: `com.tellabs.markdownopen.app`.

## Unduhan

- **Android arm64 APK**: `Markdown-Open-1.1.1-android-arm64-release-local-signed.apk`; sekitar 12,1 MiB, mode release dengan optimasi ukuran, Android 7.0/API 24+.
- **macOS Apple Silicon DMG**: `Markdown-Open-1.1.1-arm64.dmg`; sekitar 5,9 MiB; buka lalu seret Markdown Open ke Applications.
- **SHA256SUMS.txt**: checksum untuk memverifikasi kedua unduhan.

## Catatan instalasi

- Package Android baru dianggap aplikasi berbeda dari `com.markdownopen.app`, sehingga dapat terpasang berdampingan dengan versi sebelumnya.
- APK memakai signing key debug lokal untuk instalasi manual; belum memakai key distribusi publik/Google Play.
- App macOS memakai ad-hoc signing dan belum notarized dengan Apple Developer ID.
- Panduan build ada di [README versi ini](https://github.com/yusriyadi/markdown-open/blob/v1.1.1/README.md). Installer Windows belum tersedia.
